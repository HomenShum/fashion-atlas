# Private taste profile template

Do not commit the filled file to a public repository.

## Goals and wardrobe gaps
Occasions, desired categories, owned anchors, budget and date constraints: unknown until supplied.

## Positive references
For each: source/date; image inspected?; visible frame/construction/texture; user reasons; assistant hypothesis; confidence.

## Feedback ledger
Record: item; liked/disliked/neutral/unknown; owned/needed/redundant/unknown; decision; reason; source/date. Keep these independent. “No” without explanation does not establish dislike.

## Search profiles
Category → frame → construction → surface → outfit role → keywords/translations → exclusions → unknowns.

## Fit evidence
User-provided measurements and brand-size history only; record garment vs body measurements and units. Flag knee/hem placement, alteration and movement checks.

## Revision history
Date, exact correction, affected hypotheses/candidates and retained uncertainties.
